Lamma - Fullstack Engineer

Home Assignment

We want to learn how you think and how you tackle a fullstack problem end-to-end. We're not looking for a polished product - we're looking at your reasoning, your judgment, and how you collaborate with AI tools to ship something real.

The task

Build an AI-powered presentation generator.

A user provides a prompt describing the presentation or video they want. Your system generates a presentation or video output based on that prompt.

What "presentation or video" means is up to you. Define the user. Decide what the output looks like. Defend your choices.

What you'll build

The required scope:

  1. A web UI where a user can input a prompt.
  2. An AI-driven generation pipeline that turns the prompt into presentation content.
  3. A viewable output the user can see or play in the browser.

Bonuses

Optional. Pick whatever interests you - one done well beats three done superficially.

  • An editor layer - let the user tweak the generated content before finalizing.
  • Modular output - explore how the output could be extensible. For example, embedding YouTube videos, interactive elements, or plugin-style slide types.

Time budget

We expect this to take 5 – 10 hours of work over 7 calendar days.

Again - we're not looking for a production grade product. We just want to see how you think :)

Tech stack

At Lamma we use Python on the backend and React on the frontend. You're welcome to use them, or to choose anything else you're productive with. Your choice is part of what we'll discuss in the follow-up.

AI tools

We expect you to use AI tools. This is how we work at Lamma. Use whatever you're productive with - Cursor, Claude Code, Copilot, ChatGPT, anything. We're not testing your ability to work without AI; we're testing your ability to work well with AI.

In your slides (see slide deck below), tell us what you used, where it helped, and where it didn't. Be honest about the limits.

AI API access

You'll need an API key for a generative AI provider (OpenAI, Anthropic, Google, etc.). Bring your own. This is just easier for us - if cost is a real blocker, reach out.

    • What you'd do with more time
